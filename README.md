# TFXLV RADIO

Reproductor de radio y podcasts estilo Spotify, libre de rastreadores y código abierto.

## Características

* **Reproductor estilo Spotify**: Interfaz moderna y adaptable diseñada con Jetpack Compose.
* **Foreground Service audio**: Reproducción continua en segundo plano y con la pantalla apagada.
* **Descargas locales**: Guarda tus episodios favoritos para escucharlos sin conexión.
* **Metadatos vía JSON remoto**: Actualización de catálogo utilizando JSON alojado en Gitea.
* **Privacidad Primero**: Libre de rastreadores, analíticas ocultas y anuncios.

## Tech Stack

* **Kotlin**
* **Jetpack Compose** (UI / Material Design)
* **Media3 / ExoPlayer** (Reproducción de audio avanzada)
